# 📊 FinanceDashboard — Live Executive Visual Portfolio & Digest

Welcome to **FinanceDashboard**, the public web dashboard for real-time AI market digest analytics, portfolio balance tracking, active position monitors, and trade execution metrics.

## 🚀 Live Public URL
View the live dashboard at: **[https://nayankumar-k.github.io/FinanceDashboard/](https://nayankumar-k.github.io/FinanceDashboard/)**

## 💡 Overview
- **Real-Time Portfolio Metrics**: Wallet cash, total invested, unrealized P&L, cumulative P&L.
- **Active Holdings Monitor**: Real-time position tracking with entry price, current price, targets, and trailing stop losses.
- **Visual Asset Allocation**: Dynamic liquidity & portfolio exposure ratio charts.
- **Automated Sync**: Updated automatically on every trading session run by the private `AINewsAnalyst` ingestion engine.
